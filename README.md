# 我的饮食记录

本项目是一个本地优先的饮食记录 PWA。

- 私人记录与照片只保存在浏览器本机的加密数据库中。
- GitHub Pages 只托管不含私人数据的程序外壳。
- 支持完整 JSON 备份与恢复。
- 支持离线启动及添加到 Android、iPad 主屏幕。
- 单条记录最多 12 张照片，点击照片可全屏查看和左右切换。
- 一次到店记录可以添加多道菜，每道菜独立填写 0–10 分和评价；也可将逗号、顿号分隔的菜单一键拆分为多道评测。
- 首页“评测”会按地点与菜品自动汇总平均分、记录次数和最近评价；每道菜按分数区间显示不同颜色。
- “最近记录”可折叠，并可按地点查询到访次数和全部到访日期。
- 编辑或删除原始饮食记录后，评测同步变化，避免两边重复填写或内容不一致。
- 日历地点使用内置可爱字体、指定红色，单条最大 25 点并根据格子自动缩放。
- 单条长地点名可自动换成两行；同日多条记录会逐行缩小并完整显示。
- 手机和 iPad 的详情、当天记录、全年日历、设置及照片预览支持手指向右滑动返回；编辑和输入时禁用手势以防误操作。

## Android 使用

1. 使用 Chrome 打开 GitHub Pages 的 HTTPS 地址。
2. 点击右上角菜单，选择“添加到主屏幕”或“安装应用”。
3. 首次使用时设置本机用户名和密码。
4. 请定期在“设置与备份”中导出完整备份。
5. 首次联网完整打开后，网页主体会缓存到设备，之后可以离线打开。

不要清除浏览器的网站数据，否则本机记录会被删除。GitHub 仓库中不保存任何饮食记录或照片。
