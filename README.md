# 我的饮食记录

本项目是一个本地优先的饮食记录 PWA。

- 私人记录与照片只保存在浏览器本机的加密数据库中。
- GitHub Pages 只托管不含私人数据的程序外壳。
- 支持完整 JSON 备份与恢复。
- 支持离线启动及添加到 Android、iPad 主屏幕。
- 单条记录最多 12 张照片，点击照片可全屏查看和左右切换。
- 首页“评测”可按地点检索并维护菜品、分数与评价。
- 日历地点使用内置可爱字体、指定红色，单条最大 25 点并根据格子自动缩放。

## Android 使用

1. 使用 Chrome 打开 GitHub Pages 的 HTTPS 地址。
2. 点击右上角菜单，选择“添加到主屏幕”或“安装应用”。
3. 首次使用时设置本机用户名和密码。
4. 请定期在“设置与备份”中导出完整备份。
5. 首次联网完整打开后，网页主体会缓存到设备，之后可以离线打开。

不要清除浏览器的网站数据，否则本机记录会被删除。GitHub 仓库中不保存任何饮食记录或照片。
